The catalog is the starting point of an integration. One request returns everything you need to mirror Wasmou products in your own shop.

## Get the catalog

**Endpoint:** `GET /api/catalog`

| Query parameter | Type | Description |
| --- | --- | --- |
| `category_id` | integer, optional | Only products of this category. |


## Fields

### Product

| Field | Description |
| --- | --- |
| `id` | Stable product ID. |
| `name`, `description`, `image` | Display data. `description` is plain text. |
| `category_id` | Matches an entry in `categories`. |
| `kind` | `key`, `giftcard`, `topup`, `telegram_premium` or `telegram_stars`. |
| `requires_input` | `true` when the buyer must provide extra data (a player ID, an email...). |
| `input_fields` | The extra inputs to send with the purchase. Each has an `index`: send the value under that index as the key, for example `{"quantity": 1, "0": "123456789"}`. |
| `variants` | The purchasable options. |

### Variant

| Field | Description |
| --- | --- |
| `id` | Stable variant ID. Use it in `POST /products/purchase/{variantId}`. |
| `name` | For example `60 UC` or `1 Year`. |
| `price` | **Your** price in DZD, with your reseller terms applied. |
| `delivery` | `instant`, `topup` or `key`. See [delivery modes](/concepts/delivery). |
| `in_stock` | Units left for `key` variants. `null` for `instant` and `topup`, which are not counted. |
| `available` | `false` when a `key` variant is out of stock. |
| `client_stock` | Present only if you have an [allocation](/concepts/stock) for this variant. |

## Example

```bash
curl -X GET "https://api.wasmou.net/api/catalog" \
  -H "X-Api-Key: your_api_key_here"

# One category only
curl -X GET "https://api.wasmou.net/api/catalog?category_id=10" \
  -H "X-Api-Key: your_api_key_here"
```

## Good to know

- Refresh every **5 to 15 minutes**, not on every customer click. See [Sync the catalog](/guides/sync-catalog).
- `price` is your wholesale cost. Show your customers your own selling price.
- Match products and variants by `id`; names and prices can change.
