## Get all orders

## Service types

| `type` | Description | Status values |
| --- | --- | --- |
| `freefire` | Free Fire top-ups | `pending`, `success`, `failed` |
| `pubg` | PUBG Mobile top-ups | `wait`, `accept`, `reject` |
| `beinsports` | BeIN Sports subscriptions | `pending`, `completed`, `failed` |
| `product` | Catalog products | `processing`, `completed`, `delivered`, `failed`, `refunded`, `canceled` |

## Fields by type

### Free Fire
`trx_id` transaction ID · `plan_name` diamond package

### PUBG
`external_order_id` Gift4Card order ID · `product_name` UC package

### BeIN Sports
`offer_name` subscription package

### Product
`product_name`, `variant_name`. To read the delivered code, call [`GET /api/products/order/{orderId}`](/services/products#4-retrieve-order-keys).

## Example

```bash
curl -X GET "https://api.wasmou.net/api/orders" -H "X-Api-Key: your_api_key"
```

<Note>
The endpoint returns your full history; filter and sort on your side. Use it to double-check whether a purchase went through after a timeout, before retrying.
</Note>
