---
title: "Game top-ups"
description: "Verify the player, order, and follow the delivery."
---

Game top-ups (Free Fire, PUBG Mobile, Mobile Legends, Genshin Impact and more) and Telegram Premium / Stars use the standard purchase flow. See [Game top-ups and Telegram](/services/topups) for the product list and inputs.

```js
const API = "https://api.wasmou.net/api";
const headers = { "X-Api-Key": process.env.WASMOU_KEY, "Content-Type": "application/json" };

// 1. Find the product (kind "topup") and its input indexes in the catalog
const { data } = await (await fetch(`${API}/catalog`, { headers })).json();
const product = data.products.find((p) => p.name === "Free Fire (MENA)");
const variant = product.variants.find((v) => v.name === "110 Diamonds");

// 2. Verify the player ID (optional)
const check = await (await fetch(`${API}/catalog/${product.id}/verify`, {
  method: "POST", headers, body: JSON.stringify({ 0: "123456789" }),
})).json();
if (check.status === "invalid") throw new Error("Wrong player ID");

// 3. Order, then poll until the status is final
const order = await (await fetch(`${API}/products/purchase/${variant.id}`, {
  method: "POST", headers, body: JSON.stringify({ quantity: 1, 0: "123456789" }),
})).json();
```

<Note>
Failed top-ups are refunded to your wallet automatically. Poll `POST /products/orders/retrieve` until the status is `completed`, `failed` or `refunded`. See [Automate fulfilment](/guides/automate-fulfilment).
</Note>
