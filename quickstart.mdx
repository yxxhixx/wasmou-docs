title: "Quickstart"
description: "From zero to your first delivered code."
---

<Steps>
  <Step title="Get your API key">
    Sign in to the [Wasmou app](https://myapp.wasmou.net/app/api-access), open **API access** and copy your key. API access must be enabled on your account; ask support if you do not see the key.
  </Step>
  <Step title="Check that it works">
    <CodeGroup>
    ```bash curl
    curl https://api.wasmou.net/api/balance \
      -H "X-Api-Key: YOUR_API_KEY"
    ```

    ```js Node.js
    const res = await fetch("https://api.wasmou.net/api/balance", {
      headers: { "X-Api-Key": process.env.WASMOU_API_KEY },
    });
    console.log(await res.json());
    ```

    ```python Python
    import os, requests
    r = requests.get("https://api.wasmou.net/api/balance",
                     headers={"X-Api-Key": os.environ["WASMOU_API_KEY"]})
    print(r.json())
    ```
    </CodeGroup>

    ```json
    { "status": "success", "message": "Balance retrieved",
      "data": { "balance": 10001, "available_balance": 10001 } }
    ```
  </Step>
  <Step title="Read the catalog">
    ```bash
    curl https://api.wasmou.net/api/catalog -H "X-Api-Key: YOUR_API_KEY"
    ```
    Pick a variant. Its `delivery` tells you what happens after you buy: `instant`, `key` or `manual` ([details](/concepts/delivery)).
  </Step>
  <Step title="Buy it">
    ```bash
    curl -X POST https://api.wasmou.net/api/products/purchase/15 \
      -H "X-Api-Key: YOUR_API_KEY" -H "Content-Type: application/json" \
      -d '{"quantity": 1}'
    ```
    ```json
    { "status": "success", "message": "Purchase successful",
      "data": { "order_ids": ["06061206"], "count": 1 } }
    ```
  </Step>
  <Step title="Get the code">
    ```bash
    curl -X POST https://api.wasmou.net/api/products/orders/retrieve \
      -H "X-Api-Key: YOUR_API_KEY" -H "Content-Type: application/json" \
      -d '{"order_ids": ["06061206"]}'
    ```
    When `has_key` is `true`, the code is in `key`.
  </Step>
</Steps>

<Tip>
Products that need extra input (a player ID, an email) list it in `input_fields` in the catalog. Send those fields in the purchase body.
</Tip>
