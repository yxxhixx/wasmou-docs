<Update label="October 2026 (3)" description="WooCommerce plugin and safe purchase retries">
  **New**
  - **Wasmou for WooCommerce**: a free WordPress plugin to sell Wasmou products in your own store, with one-click import, automatic prices and stock, and automatic delivery of codes. See [WordPress / WooCommerce plugin](/guides/woocommerce-plugin).
  - `POST /products/purchase/{variantId}` accepts an `Idempotency-Key` header. A retry with the same key returns the original answer and never charges twice.
  - `GET /catalog` accepts `lang` (`en`, `fr`, `ar`) and returns a `guide` (activation steps) per product, plus `async` and `warranty` per variant.
</Update>

<Update label="October 2026 (2)" description="Simpler delivery model">
  **Changed**
  - Every product is now delivered automatically. The catalog `delivery` field is `instant`, `topup` or `key`; the `manual` value no longer appears.
  - Deposits are available by Baridi Mob / CCP transfer.
</Update>

<Update label="October 2026" description="Instant supplier catalog and game top-ups">
  **New**
  - **Hundreds of gift cards delivered instantly**, with names and prices that follow our supplier automatically.
  - **Game top-ups and Telegram**: Free Fire (MENA), PUBG Mobile (Auto), Mobile Legends (Global), Delta Force, Genshin Impact (Global), PUBG: New State, Whiteout Survival, Telegram Premium and Telegram Stars. They are catalog products with a `kind` field, ordered with the normal purchase endpoint. See [Game top-ups and Telegram](/services/topups).
  - `POST /catalog/{id}/verify` checks a game player ID before you pay.
  - Catalog products have a new `kind` field, `delivery` can be `topup`, and `input_fields` is now a list with an `index` per field (send the value under that index in the purchase body).

  **Removed**
  - The dedicated Free Fire, PUBG (Gift4Card) and BeIN Sports endpoints (`/freefire/*`, `/pubg/*`, `/beinsports/*`) and their order types in `GET /orders`. Use the catalog and `POST /products/purchase/{variantId}` instead. Their old order history is no longer available through the API.
</Update>

<Update label="October 2026" description="Wasmou V3">
  **New**
  - `GET /catalog`: the full catalog with prices, delivery mode, stock and required inputs in one call.
  - `GET /stock` and `GET /stock/{variantId}`: per-client stock allocations. Catalog and variant responses include `client_stock` when you have an allocation.
  - Documentation moved to this site.

  **Changed**
  - **New API host: `https://api.wasmou.net/api`** (was `https://gateway.wasmou.net/api`). Only the hostname changed: paths, headers, request bodies and responses are the same. To migrate, replace the host in your configuration.
  - Responses no longer start with a byte-order mark (an invisible character before the opening brace).
  - The public product search (`/api/products/search`, `/api/products/filter`) no longer returns supplier cost information.

  **Removed**
  - Internet / ADSL top-ups (`/api/internet/*`), social-media services (`/api/smm/*`), Flexy mobile top-ups (`/api/flexy/*`), IMEI services and the IPTV product range. Their endpoints return `404`. IPTV will return as a separate API.
</Update>
